Algorithm, exactly:

3. Filter the chosen pair: `$parts = @($hm, $hd) | Where-Object { $_ -and $_ -ne 'Not available' }`.
4. ## Trust Boundaries

| Boundary | Description |

| background runspace → UI thread | Read results cross only inside the 150 ms tick; a failed read must not be confused with a good one |
