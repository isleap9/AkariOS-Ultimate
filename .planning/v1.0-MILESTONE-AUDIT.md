## Gaps Detail

### Critical

**C-1 — `02-02-PLAN.md`'s mocked harnesses are stale and now FAIL on the current tree**

`.planning/phases/02-hardware-spec-cards/02-02-PLAN.md:132, 174, 216` shadow CIM with:

```powershell
function Get-CimInstance{[CmdletBinding()]param([string]$ClassName) …}
```

Phase 4-03 (`a0750ed`) added `-OperationTimeoutSec 10` to all eight spec-read calls. The mock rejects it (`A parameter cannot be found that matches parameter name 'OperationTimeoutSec'`). The rejection is swallowed by `Get-Specs`' per-field try/catch, so the harnesses silently produce **0 volumes / `_Status=Failed`** and exit 1 with `FAIL: expected 3 fixed volumes, got 0`. `02-VERIFICATION.md:4` records `status: passed` based on harnesses that can no longer run.

Product code is unaffected — every behaviour those harnesses cover was re-verified live. Phase 4's own plan did update its mock (`04-03-PLAN.md:198`).

*Affects:* SPEC-03, SPEC-04, SPEC-05 (evidence reproducibility only).
