# Milestone v1.0: Home Page

**Status:** ✅ SHIPPED 2026-10-09
**Phases:** 1-4
**Total Plans:** 8

## Overview

Add a Home page to AkariOS-Ultimate — a PowerShell 5.1 + WPF tweaking tool — that displays live system specs (CPU, RAM, GPU, disk, motherboard/BIOS, Windows edition/build) in a card grid, refreshed every time Home is shown. The Home page is the default landing tab and provides read-only system information at a glance.

## Phases

### Phase 1: Spec Query Engine

**Goal**: Reliable background queries for CPU, RAM, and Windows specs with per-field fallback
**Depends on**: Nothing (first phase)
**Plans**: 1 plan

Plans:

- [x] 01-PLAN.md — CIM/registry spec query engine with per-field fallback

**Details:**

- Get-Specs function returning grouped hashtable (CPU, RAM, Windows)
- Invoke-Code -Result parameter for runspace result capture

## Milestone Summary

**Key Decisions:**

- Home is the default landing tab — User wants specs-first experience on launch
- Card grid layout — Chosen over matching existing tweak rows; overview reads better as cards
- Live refresh on every Home show — User chose live over button/cached; specs never stale
- Show all five spec groups + edition/build only — All hardware groups selected; Windows detail limited to edition + build
- GPU VRAM read from registry HardwareInformation.qwMemorySize when WMI caps at 4 GB — WMI AdapterRAM is uint32; real VRAM >4 GB needs the registry
- BIOS date formatted in UTC with invariant culture — Avoids off-by-one dates across timezones/cultures
- Disk card shows only the system drive — User request during Phase 3
- Copy text is built from the same shared card model — One source means the clipboard text can never drift from what is on screen
- Health colour is suppressed when a group's _Status is Failed — A failed read must never colour a value with a real threshold brush
- Spec-read watchdog: 20 s deadline (later raised to 30 s), abandoned with BeginStop — A hung WMI provider must not dim Home for the session
- Only the spec read may write $script:SpecData — A dormant second writer could install a stale-shape composite
- CPU cores/threads summed across every socket — Multi-socket machines were under-reported
