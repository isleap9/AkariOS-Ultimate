# Quick Task 261009-n88: bring all console-only tweaks into the app (no terminal window) - Context

**Gathered:** 2026-10-09
**Status:** Ready for planning

<domain>
## Task Boundary

Convert all 7 `-Kind Console` tweaks into in-app tweaks that run in the background runspace via `Invoke-Code`, with no separate terminal window:

- Refresh: `autounattend`, `updates-drivers-block` (`Tweaks/Refresh.ps1:40,43`)
- Graphics: `driver-install-settings`, `driver-debloat` (`Tweaks/Graphics.ps1:245,248`)
- Advanced: `smt-ht`, `core1-thread1`, `priority` (`Tweaks/Advanced.ps1:934,937,940`)

Root cause (from `.planning/todos/pending/2026-10-09-console-tweaks-in-app.md`): commit `d38e5e1` deleted the numbered folders, so the `Start-Process powershell.exe -File "$Root\<Script>"` Run handler in `Akari.ps1` launches a missing file and the click does nothing. Script bodies are recoverable with `git show d38e5e1^:"<folder>/<file>.ps1"`.

</domain>

<decisions>
## Implementation Decisions

### Scope / size
- All 7 tweaks in this one quick task. Split into several plans/commits (e.g. one per category plus a shared-infrastructure plan) so each commit is atomic and reviewable.
- Remove the Console launch path (`-Kind Console`, `-Script`, the `Run` → `Start-Process` branch) once nothing uses it.

### Menus
- Each script's `Read-Host` numbered menu (`switch ($choice)`) becomes `-Kind Group` `-Actions` sub-buttons, following the existing `reinstall` Group (`Tweaks/Refresh.ps1:15`).

### Typed inputs (account name, USB drive letter, game EXE ID, priority level)
- Pop-up dialog: a small dark-theme WPF dialog shown on the UI thread when the button is clicked, before the background work starts. Uses existing `Ink` tokens (`Bg S1 S2 Bd Tx Mu`).
- USB drive letter: a dropdown of detected removable/USB drives rather than free text.
- Cancel aborts cleanly: nothing runs, one log line.
- Collected values are passed into the runspace body (e.g. injected as variables ahead of the body), never read with `Read-Host` in the runspace.

### File pickers
- Shown on the UI thread before the run (the runspace is not a safe place for `OpenFileDialog`). The chosen path is passed into the body. Cancel = nothing runs.

### Auto-reboots
- Replace every `shutdown /r /t 0` / `shutdown -r -t 00` with a completion step: when the work finishes, the UI asks "Restart now?" Yes/No. Yes restarts; No logs "Restart required".
- The prompt is raised by the host on the UI thread after the runspace completes (tweak bodies must not pop MessageBoxes — AGENTS.md logging rules).

### Claude's Discretion
- Exact dialog layout, and the mechanism for passing inputs/reboot flags between UI thread and runspace (e.g. new optional `Add-Tweak`/action keys such as `Inputs`, `Pick`, `Reboot`).
- Whether `Read-Host`/`Pause`/`Clear-Host` shims in `$Helpers` need tightening so a missed prompt can never hang the runspace.
- Internet-check preambles in recovered scripts: convert to the existing `Write-Log 'Internet connection required'; return` guard style (`Tweaks/Graphics.ps1:254`).

</decisions>
